## 📌 Overview

This repository houses the source code for the personal developer portfolio of **Mohit Kumar**, a Computer Science & Engineering undergraduate at **GL Bajaj Institute Of Technology And Management (AKTU)**.

The website serves as a single source of truth for all technical capabilities, enterprise-grade projects, workflow automations, and academic credentials. It was engineered to deliver a seamless experience for engineering recruiters, engineering managers, and technical peers.

### 🎯 Key Goals:
- **Instant Recruiter Evaluation:** Key competencies, project metrics, and verified links are surfaced within 3 seconds of page load.
- **Single Source of Truth:** Every detail (projects, tech stacks, bullet metrics, education) strictly aligns with Mohit's verified curriculum vitae.
- **High Visual Fidelity:** Obsidian slate theme (`#090d16`), fine borders, cyan/indigo ambient highlights, and clean typography (`Plus Jakarta Sans`, `Space Grotesk`, `JetBrains Mono`).
- **Zero Framework Overhead:** Instant First Contentful Paint (FCP) and near-zero Total Blocking Time (TBT) through pure HTML/CSS/JS.

1. **Obsidian Palette & Glassmorphism:**
   - Deep background base: `#090d16` (slate obsidian)
   - Secondary card surfaces: `rgba(15, 23, 42, 0.7)` with `backdrop-filter: blur(12px)`
   - Subtle accent borders: `rgba(255, 255, 255, 0.08)`
   - Strategic luminous accents: Electric Cyan (`#38bdf8`) & Soft Indigo (`#818cf8`)

2. **Typography System:**
   - Primary Body: **Inter / Plus Jakarta Sans** (clean, readable sans-serif)
   - Section Headings: **Space Grotesk** (engineered, geometric display)
   - Technical & Code Cards: **JetBrains Mono** (crisp monospaced code styling)

3. **Motion & Interaction Design:**
   - Smooth anchor scrolling with sticky header offset compensation.
   - Interactive hover cards with subtle upward lift (`translateY(-4px)`).
   - Fully respected accessibility via `@media (prefers-reduced-motion: reduce)`.

## 💻 Local Setup & Quick Start

Because this project is built using vanilla web standards, **no build step, bundler, or `npm install` is required**.

### Method 1: Instant Browser Launch
Simply double-click [`index.html`](index.html) or right-click and choose **Open With > Google Chrome** (or any modern browser).

### Method 2: Python Local Server
```bash
# Clone the repository
git clone https://github.com/imohitkumarcse/html_projects.git

# Navigate into the project folder
cd html_projects

# Start a local HTTP server
python -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.

### Method 3: Node.js (npx)
```bash
npx serve .
```

### Method 4: VS Code Live Server Extension
1. Open this repository folder in **VS Code**.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click [`index.html`](index.html) and select **"Open with Live Server"**.

## 🚀 Deployment Guide

### Deploy to GitHub Pages
1. Push your code to your GitHub repository:
   ```bash
   git add .
   git commit -m "feat: complete developer portfolio and documentation"
   git push origin main
   ```
2. Navigate to your repository on **GitHub**.
3. Go to **Settings** > **Pages** (under the "Code and automation" sidebar).
4. Under **Branch**, select `main` and set folder to `/ (root)`.
5. Click **Save**. Within 1–2 minutes, your portfolio will be live at:
   ```text
   https://imohitkumarcse.github.io/html_projects/
   ```

### Deploy to Vercel
1. Install Vercel CLI (optional) or visit [vercel.com](https://vercel.com).
2. Connect your GitHub account and import `imohitkumarcse/html_projects`.
3. Keep default settings (Framework Preset: **Other**) and click **Deploy**.
4. Vercel will instantly publish the portfolio to a custom `.vercel.app` URL with automated HTTPS and CDN edge caching.

## 📊 Performance & Accessibility

- ⚡ **Zero Bloat:** Entire application weighs under **75 KB** uncompressed (excluding external web fonts/CDN icons).
- 📱 **Fluid Responsiveness:** Engineered mobile-first using modern CSS Grid (`minmax()`), Flexbox layouts, and dynamic clamp sizing (`clamp(2rem, 5vw, 3.8rem)`).
- ♿ **Accessibility First:** Semantic tags (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<nav>`), ARIA labels, modal escape-key listeners, and focus traps.
- 🎨 **Contrast Compliance:** All text tokens exceed **WCAG 2.1 AA** contrast ratios against dark surface backgrounds.
